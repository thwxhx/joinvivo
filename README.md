# 💜 VIVOSPORTS – Social Hub

> All things VIVOSPORTS. One place.

A modern, minimalistic landing page bringing all VIVOSPORTS social media communities together in one place.

## ✨ Features

- 🎨 Modern and minimalistic design
- 💜 VIVOSPORTS signature colour (`#796fc7`)
- 🌙 Dark mode UI
- 📱 Fully responsive layout
- 💬 WhatsApp Group
- 📢 WhatsApp Channel
- ✈️ Telegram Channel
- 📸 Instagram
- ⚡ Smooth animations and transitions
- 🚀 Lightweight and fast loading

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- Font Awesome / Lucide Icons

## 🚀 Deployment

This project is deployed using **GitHub Pages**.

1. Fork or clone this repository.
2. Upload the project files.
3. Navigate to Settings → Pages.
4. Select the `main` branch.
5. Click Save.
6. Your website will be live shortly!

## ⚙️ Customization

You can customize the website by editing:

- `index.html` – Website structure and social links.
- `style.css` – Colours, layout and styling.
- `script.js` – Animations and interactions.
